# frontend-project
Selamat datang di repository proyek web Fakultas Teknologi Informasi! Proyek ini bertujuan untuk membangun rancangan Frontend dari website fakultas dan memenuhi tugas matakuliah Pemograman Web. Dengan menggunakan teknologi modern, proyek ini memberikan tampilan visual yang lebih menarik dari desain web sebelumnya, penggunaan menu dan pilihan pada web ini, juga disesuaikan dengan web sebelumnya.

Fitur Utama
Kemudahan dalam mengakses beberapa menu dan fitur  yang tersedia pada website
Desain yang firendly user
dan tidak ada pengurangan dari fitur website yang lama, untuk memudahkan pengguna dalam mengakses fitur yang ada pada web
